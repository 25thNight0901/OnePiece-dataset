# One Piece Dataset

This repository contains JSON datasets based on the **One Piece** universe.

The datasets will be used as the foundation for an API during the Web Development course.

## Datasets

### characters.json

Contains information about One Piece characters.

Each character contains information such as:

- ID
- Name
- Description
- Age
- Active status
- Birth date
- Image
- Rarity
- Abilities
- Role
- Pirate crew

### pirate-crews.json

Contains information about the different pirate crews in One Piece.

Each pirate crew contains information such as:

- ID
- Name
- Captain
- Ship
- Active status
- Jolly Roger image

## Theme

The theme of this dataset is **One Piece**.
